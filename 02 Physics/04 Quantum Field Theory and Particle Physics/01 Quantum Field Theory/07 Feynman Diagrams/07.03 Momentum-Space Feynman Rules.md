---
title: "Momentum-Space Feynman Rules"
---

> [!TLDR]
> Momentum-space rules replace vertex-position integrals with momentum-conservation constraints and leave one integral for each independent loop momentum.

Integrating each internal vertex position gives a four-momentum delta distribution. After using these constraints, one overall delta distribution remains for total momentum conservation. Internal line momenta remain as variables constrained at each vertex.

For a connected graph, each internal line initially has a momentum variable. Vertex conservation removes one variable per independent vertex constraint; one constraint is redundant because it states overall conservation. Thus a tree has no free internal momentum after the external momenta are fixed, whereas each independent loop leaves one four-momentum integral.

Use the rule list to assign a momentum routing before simplifying denominators. Then use the bubble example to check that changing an internal routing changes the integration variable, not the physical channel. A consistent regulator is needed when such variable changes are applied to divergent integrals.
