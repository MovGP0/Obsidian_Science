> [!TLDR]
> These rounded SI values are sufficient for the numerical estimates in these notes.

## Physical quantities

| Symbol | Unit | Quantity | Description |
| --- | --- | --- | --- |
| $\mechanical c$ | $\unit{m\,s^{-1}}$ | Speed of light in vacuum | $\quantity{2.998\times10^8}{m\,s^{-1}}$. |
| $\mechanical h$ | $\unit{J\,s}$ | Planck constant | $\quantity{6.626\times10^{-34}}{J\,s}$. |
| $\mechanical{\hbar}$ | $\unit{J\,s}$ | Reduced Planck constant | $\mechanical h/(2\pi)$, $\quantity{1.0546\times10^{-34}}{J\,s}$. |
| $\thermal{k_B}$ | $\unit{J\,K^{-1}}$ | Boltzmann constant | $\quantity{1.381\times10^{-23}}{J\,K^{-1}}$. |
| $\electric e$ | $\unit{C}$ | Elementary charge | $\quantity{1.602\times10^{-19}}{C}$. |
| $\electric{\varepsilon_0}$ | $\unit{F\,m^{-1}}$ | Vacuum permittivity | $\quantity{8.854\times10^{-12}}{F\,m^{-1}}$. |
| $\mechanical{m_e}$ | $\unit{kg}$ | Electron mass | $\quantity{9.109\times10^{-31}}{kg}$. |
| $\mechanical{m_p}$ | $\unit{kg}$ | Proton mass | $\quantity{1.673\times10^{-27}}{kg}$. |
| $\mechanical{m_n}$ | $\unit{kg}$ | Neutron mass | $\quantity{1.675\times10^{-27}}{kg}$. |
| $N_A$ | $\unit{mol^{-1}}$ | Avogadro constant | $\quantity{6.022\times10^{23}}{mol^{-1}}$. |
| $\mechanical G$ | $\unit{m^3\,kg^{-1}\,s^{-2}}$ | Gravitational constant | $\quantity{6.674\times10^{-11}}{m^3\,kg^{-1}\,s^{-2}}$. |
