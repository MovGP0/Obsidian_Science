> [!TLDR]
> Boltzmann and Gibbs entropy agree for uniform probabilities, but their use away from equilibrium depends on the level of description.

The table compares the two definitions introduced in this chapter.

| Property | Boltzmann entropy | Gibbs entropy |
| --- | --- | --- |
| Definition | ${\thermal{S}}={\thermal{k}_{\mathrm B}}\ln\Omega$ | ${\thermal{S}}_G=-{\thermal{k}_{\mathrm B}}\sum_i p_i\ln p_i$ |
| Probability distribution | Uniform over the accessible states | Any normalized distribution |
| Additivity | Independent systems | Independent systems |
| Connection to thermodynamics | Direct in the microcanonical description | Through constrained maximization |
| Natural ensemble | Microcanonical | All ensembles |
| Evolution | The macroscopic description tends toward equilibrium | Fine-grained entropy is constant under Hamiltonian evolution |

> [!note] Additivity clarification
> The source lists Gibbs entropy as additive without qualification. The joint entropy equals the sum of the subsystem entropies for independent distributions. Correlations require an additional term; additivity is not automatic for a correlated pair.

The probability-distribution row describes the uniform ensemble that makes the Boltzmann and Gibbs formulas equal. Boltzmann entropy itself is assigned to a macrostate through its compatible-state count. It need not imply that every actual nonequilibrium preparation is uniformly spread over that macrostate.

For two allowed states with unequal probabilities, Gibbs entropy depends on those weights, while the count of allowed states remains two. For a transported continuous ensemble, fine-grained Gibbs entropy is conserved with the reference measure fixed. For a macrostate that changes during relaxation, Boltzmann entropy can change because the compatible region changes. These comparisons specify which object evolves before discussing its entropy; otherwise the same symbol can hide different questions.

The evolution row needs care. Liouville's theorem conserves the fine-grained Gibbs entropy. Thermodynamic entropy can still rise because a macroscopic description does not resolve arbitrarily fine phase-space structures.

**Coarse-graining** replaces this detailed information with averages over finite cells. This can describe an approach to equilibrium and an increase in macroscopic entropy.

For a fixed partition, replacing the density inside each cell by its cell average removes internal detail. Convexity of $\rho\ln\rho$ makes the resulting Gibbs entropy at least as large as that of the original fine-grained density, with the same reference convention. This compares two descriptions at one time. It does not prove that coarse-grained entropy at a later time exceeds its value at every earlier time. Recurrence and specially prepared initial distributions are reasons to keep that distinction explicit.

> [!note] Scope clarification
> The source says that coarse-grained entropy grows with time. This is a statistical relaxation statement under suitable assumptions. A fixed coarse-graining of an arbitrary Hamiltonian system does not give an exact, universally monotonic entropy law.

## Physical quantities

| Symbol | Unit | Quantity | Description |
| --- | --- | --- | --- |
| ${\thermal{S}}$ | $\unit{J\,K^{-1}}$ | Entropy | Boltzmann or Gibbs entropy, as specified by the context or subscript. |
| ${\thermal{k}_{\mathrm B}}$ | $\unit{J\,K^{-1}}$ | Boltzmann constant | The conversion factor between microscopic counting and thermodynamic entropy. |
