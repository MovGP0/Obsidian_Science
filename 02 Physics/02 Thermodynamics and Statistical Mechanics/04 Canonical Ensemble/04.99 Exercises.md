The questions below are transcribed from the supplied chapter. Worked solutions are added in these notes; the separate source answer-key pages for this chapter were not supplied in this batch.

Work through the set by model choice. First use independent oscillator modes to test factorization without a particle factorial. Then use the three-level system to test normalization and both temperature limits with a finite sum. Compare the quantum rotor with classical equipartition to identify which modes remain active. The pressure exercise changes the spatial dimension and requires a new unit for the conjugate force. Finish with demagnetization, where field changes do work and the path keeps entropy, rather than temperature, fixed.

For each answer, state one assumption that would change the result. Useful examples are coupling the oscillators, adding a fourth level, activating vibrations, allowing particles to leave the gas, or admitting heat during demagnetization. The worked solutions explain these model boundaries; they are calculations, not measured validation data.
