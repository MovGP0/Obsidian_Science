Use the exercises to test different model decisions. In Exercise 5.1, state which reservoir variables remain fixed during the entropy derivative before doing algebra. In Exercise 5.2, separate heat from chemical work before interpreting a temperature derivative. In Exercise 5.3, test the mechanical stability condition before taking a square root. In Exercise 5.4, identify the pressure range in which the infinite column sum is normalizable.

After each solution, change one assumption and predict what must be recalculated: activate an internal gas state, vary chemical potential with temperature, retain excluded volume, or limit the number of adsorption layers. These changes test whether the derivation can be transferred to a new model. The source questions and the worked answers are kept together so that each assumption can be checked against the calculation that uses it.
