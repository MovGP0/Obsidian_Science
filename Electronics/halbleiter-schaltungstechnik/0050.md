# 1.2 Aufbau einer Diode

Die Herstellung von Dioden erfolgt in einem mehrstufigen Prozess auf einer Halbleiterscheibe (*wafer*), die anschließend durch Sägen in kleine Plättchen (*die*) aufgeteilt wird.
