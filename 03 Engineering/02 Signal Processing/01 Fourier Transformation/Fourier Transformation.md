## Overview

| Transform Name                                  | Time Domain            | Time Length   | Amplitude            | Frequency Domain         | Frequency Length  | Notes                                       |
| ----------------------------------------------- | ---------------------- | ------------- | -------------------- | ------------------------ | ----------------- | ------------------------------------------- |
| **Fourier Transform (FT)**                      | Continuous             | Infinite      | Continuous           | Continuous               | Infinite          | Idealized, continuous signals               |
| **Inverse Fourier Transform (IFT)**             | ^^                     | ^^            | ^^                   | ^^                       | ^^                | Recovers signal from FT                     |
| **Discrete-Time Fourier Transform (DTFT)**      | Discrete               | Infinite      | Continuous           | Continuous (periodic)    | Infinite          | Theoretical for sampled signals             |
| **Discrete Fourier Transform (DFT)**            | Discrete               | Finite        | Continuous           | Discrete                 | Finite            | Assumes periodicity over window             |
| **Quantized Discrete Fourier Transform (QDFT)** | Discrete               | Finite        | Discrete (quantized) | Discrete                 | Finite            | Adds quantization noise floor               |
| **Short-Time Fourier Transform (STFT)**         | Continuous or Discrete | Finite window | Continuous           | Continuous or Discrete   | Finite per window | Time–frequency analysis                     |
| **Continuous Wavelet Transform (CWT)**          | Continuous             | Infinite      | Continuous           | Continuous (scale+shift) | Infinite          | Uses scalable wavelets instead of sinusoids |
| **Discrete Wavelet Transform (DWT)**            | Discrete               | Finite        | Continuous           | Discrete (scale+shift)   | Finite            | Often implemented via filter banks          |
| **Quantized Discrete Wavelet Transform (QDWT)** | Discrete               | Finite        | Discrete (quantized) | Discrete (scale+shift)   | Finite            | Used in compression (e.g., JPEG2000)        |
## Forward and Inverse Formulas

| Transform Name                              | Time → Frequency                                                                                    | Frequency → Time                                                                                                                  | Notes                                                                                                                            |
| ------------------------------------------- | --------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| Fourier Transform (FT)                      | $X(f) = \int_{-\infty}^\infty x(t)\,e^{-i 2\pi f t}\, dt$                                           | $x(t) = \int_{-\infty}^\infty X(f)\,e^{i 2\pi f t}\, df$                                                                          |                                                                                                                                  |
| Discrete-Time Fourier Transform (DTFT)      | $X(e^{i\omega}) = \sum_{n=-\infty}^\infty x[n]\,e^{-i \omega n}$                                    | $x[n] = \frac{1}{2\pi} \int_{-\pi}^{\pi} X(e^{i\omega})\,e^{i \omega n} \, d\omega$                                               |                                                                                                                                  |
| Discrete Fourier Transform (DFT)            | $X[k] = \sum_{n=0}^{N-1} x[n]\,e^{-i \frac{2\pi}{N} k n}$                                           | $x[n] = \frac{1}{N} \sum_{k=0}^{N-1} X[k]\,e^{i \frac{2\pi}{N} k n}$                                                              |                                                                                                                                  |
| Quantized Discrete Fourier Transform (QDFT) | $X_Q[k] = \sum_{n=0}^{N-1} Q(x[n])\,e^{-i \frac{2\pi}{N} k n}$                                      | $x_Q[n] = Q\left( \frac{1}{N} \sum_{k=0}^{N-1} X_Q[k]\,e^{i \frac{2\pi}{N} k n} \right)$                                          | $Q(\cdot)$ is a quantization function<br>(e.g., rounding to nearest fixed step)                                                  |
| Short-Time Fourier Transform (STFT)         | $X(t, f) = \int_{-\infty}^\infty x(\tau)\,w(\tau-t)\,e^{-i 2\pi f \tau}\, d\tau$                    | $x(t) = \frac{1}{C_w} \int_{-\infty}^\infty \int_{-\infty}^\infty X(\tau, f)\,w(t-\tau)\,e^{i 2\pi f t} \, df \, d\tau$           |                                                                                                                                  |
| Continuous Wavelet Transform (CWT)          | $W(a,b) = \frac{1}{\sqrt{\|a\|}} \int_{-\infty}^\infty x(t)\,\psi^*\!\left(\frac{t-b}{a}\right) dt$ | $x(t) = \frac{1}{C_\psi} \int_{-\infty}^\infty \int_{-\infty}^\infty W(a,b)\,\psi\!\left(\frac{t-b}{a}\right) \frac{da\,db}{a^2}$ |                                                                                                                                  |
| Quantized Discrete Wavelet Transform (QDWT) | $W_Q(j,k) = \text{DWT}\left( Q(x[n]) \right)$                                                       | $x_Q[n] = Q\left( \text{IDWT}(W_Q(j,k)) \right)$                                                                                  | Same as DWT but input samples \( x[n] \) are quantized                                                                           |
| Discrete Wavelet Transform (DWT)            |                                                                                                     |                                                                                                                                   | Similar to CWT but evaluated at discrete scales and positions; often via filter banks.<br>Inverse DWT via synthesis filter bank. |
