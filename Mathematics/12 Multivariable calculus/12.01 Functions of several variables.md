> [!TLDR]
> A function assigns one output to each allowed input; domains, graphs, and level sets show different parts of this assignment.

## Inputs and outputs

A function $f:D\to\mathbb R$ assigns one real number to each point in a domain $D\subseteq\mathbb R^n$. The point $\mathbf x=(x_1,\ldots,x_n)$ contains $n$ independent input coordinates. The codomain is the declared output set. The image $f(D)$ is the set of outputs that actually occur. These sets need not be equal.

A scalar-valued function has one real output. A vector-valued map $F:D\to\mathbb R^m$ has components $F_1,\ldots,F_m$:

$$
F(\mathbf x)=(F_1(\mathbf x),\ldots,F_m(\mathbf x)).
$$

The number of input variables and the number of output components are different facts. For example, $F(s,t)=(s+t,st,s^2)$ has two input variables and three output components. Calling it a three-variable function would confuse these roles.

## Determine the domain before calculating

For real functions, a denominator cannot vanish, an even root needs a nonnegative argument, and a logarithm needs a positive argument. Combine all restrictions by intersection. A formula has a maximal real domain, but a problem can specify a smaller domain.

Consider

$$
f(x,y)=\frac{\sqrt{9-x^2-y^2}}{y-x}.
$$

The square root requires $x^2+y^2\leq9$. The denominator requires $y\ne x$. Thus its maximal domain is a closed disk with the diagonal diameter removed. Points on the circular boundary are allowed except where $y=x$. The domain is neither open nor closed in $\mathbb R^2$: it contains some boundary points, but omits limits on the removed diameter.

A point is interior if a small open disk about it lies inside the domain. A boundary point has points of the domain and its complement in every disk about it. Later derivative theorems usually assume an open domain, so derivatives can be tested in every sufficiently small direction.

## Graphs and level sets

The graph of a scalar function of two variables is the subset

$$
\{(x,y,z)\in\mathbb R^3:(x,y)\in D,\ z=f(x,y)\}.
$$

It displays the output as a third coordinate. A level set instead fixes an output value $c$ and retains input points:

$$
L_c=\{\mathbf x\in D:f(\mathbf x)=c\}.
$$

For $f(x,y)=x^2+y^2$, the level sets for $c>0$ are circles of radius $\sqrt c$. For $c=0$, the set is the origin. For $c<0$, it is empty. The graph is a paraboloid; a level curve is its horizontal slice projected onto the input plane. Distinct levels cannot intersect because a function has only one output at each input.

The figure keeps the input plane visible. Each circle contains inputs with the same value. The arrow records a direction of change, developed in [[12.06 Gradients and extrema]]. A level set need not be a smooth curve: $xy=0$ is two crossing lines.

## Worked example: a vector map and its image

Let $F(s,t)=(s\cos t,s\sin t)$ with $0\leq s\leq2$ and $0\leq t<2\pi$. Each output satisfies

$$
x^2+y^2=s^2(\cos^2t+\sin^2t)=s^2\leq4.
$$

Conversely, each nonzero point in the disk of radius $2$ has a radius $s$ and an angle in the specified interval. The origin comes from every pair $(0,t)$. The image is therefore the whole disk. The map is not one-to-one, even though each input has one output. A function need not have an inverse.

Its graph is a subset of $\mathbb R^4$, consisting of $(s,t,s\cos t,s\sin t)$. Its image is the disk in $\mathbb R^2$. These are different sets. [[12.08 Coordinate substitution]] uses this map to transform integrals.

## Practice

1. Find the real domain of $g(x,y)=\log(y-x^2)/(x+1)$.
2. Describe all level sets of $h(x,y)=x^2-y^2$, including the zero level.

## Worked answers

1. The logarithm requires $y-x^2>0$, so $y>x^2$. The denominator excludes $x=-1$. The domain is the region strictly above the parabola, with the part of the vertical line $x=-1$ in that region removed. Both restrictions are strict, so the resulting set is open.
2. For $c>0$, $x^2-y^2=c$ gives hyperbolas that open in the positive and negative $x$ directions. For $c<0$, write $y^2-x^2=-c$; the hyperbolas open in the $y$ directions. For $c=0$, factor $(x-y)(x+y)=0$, which gives the two lines $y=x$ and $y=-x$. A zero level can have a crossing even when the defining function is smooth.
