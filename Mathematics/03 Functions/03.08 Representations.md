> [!TLDR]
> A verbal rule, formula, table, and graph describe the same function only when they preserve its domain and every assigned output.

## One assignment, several descriptions

A function contains a domain, a codomain, and an output assignment. A **verbal rule** explains the assignment in words. A **formula** expresses it through symbols. A **table** records input–output pairs. A **graph** places the same pairs in a coordinate plane. Each representation makes some features easier to see, but no representation may change the assignment silently. Review the precise set language in [[03.01 Function definitions]].

A table can specify an entire function when the domain is exactly its listed inputs. If the domain is an interval or all real numbers, a finite table usually shows only a sample. Many different functions can share the same sampled pairs. Similarly, joining table points by straight line segments adds an interpolation rule. That rule needs separate justification; it does not follow from the table alone.

A graph also has conventions. A filled point includes a value. An open point excludes that value at that position. A continuous curve between marked inputs asserts values at intermediate inputs. A collection of isolated points specifies a discrete domain unless more information is supplied. The drawing window is not automatically the domain.

## Worked example: keep a piecewise rule unchanged

Suppose the domain is $[-2,3]$ and the verbal rule is: “For a negative input, return its distance from zero. For a nonnegative input, return one plus half its square.” With codomain $\mathbb R$, the formula is

$$
f:[-2,3]\to\mathbb R,\qquad
f(x)=
\begin{cases}
-x,&-2\leq x<0,\\
1+\frac{x^2}{2},&0\leq x\leq3.
\end{cases}
$$

For a negative real number, distance from zero is its absolute value $|x|=-x$, which explains the first branch. “Half its square” is $x^2/2$, whereas “the square of half the input” would mean $(x/2)^2=x^2/4$. Parentheses preserve this verbal distinction.

Calculate sample outputs branch by branch:

| Input $x$ | Branch calculation | Output $f(x)$ |
| --- | --- | --- |
| $-2$ | $-(-2)$ | $2$ |
| $-1$ | $-(-1)$ | $1$ |
| $0$ | $1+0^2/2$ | $1$ |
| $1$ | $1+1^2/2$ | $3/2$ |
| $2$ | $1+2^2/2$ | $3$ |
| $3$ | $1+3^2/2$ | $11/2$ |

To draw the exact graph, use the line $y=-x$ from $x=-2$ up to but excluding $0$. Mark $(-2,2)$ filled and $(0,0)$ open. Then draw the parabola segment $y=1+x^2/2$ from $0$ through $3$, with filled endpoints $(0,1)$ and $(3,11/2)$. The table alone would not reveal the open point $(0,0)$, because zero uses the other branch.

The first branch has range $(0,2]$: its outputs approach zero but never equal it. The second branch has range $[1,11/2]$. Their union is $(0,11/2]$. Thus range information from the formula agrees with the graph's occupied heights. There is a jump at zero even though the table gives equal values at $-1$ and $0$.

## Why samples do not determine a general rule

Consider the table $(0,1),(1,3),(2,5)$. The affine rule $p(x)=2x+1$ matches it. So does

$$
q(x)=2x+1+x(x-1)(x-2).
$$

At each sampled input, one factor in the added product is zero. Hence $p$ and $q$ have the same table there. But $p(3)=7$ while $q(3)=7+3\cdot2\cdot1=13$. A statement that the function is affine, meaning of the form $mx+b$, would select $p$ from these candidates. Without such a condition, extending a pattern is a hypothesis rather than a deduction.

When converting a verbal statement into a formula, first state the domain and boundary rules. When reading a formula into a table, substitute exact values before rounding. When reading a graph, distinguish exact marked values from estimates. A finite drawing has limited precision and cannot by itself prove an identity for every input.

## Practice

1. On domain $\{0,1,2,3\}$, a rule says “subtract the input from $4$, then square the result.” Give its formula and complete table. Describe its graph.
2. A table has pairs $(0,2),(1,5),(2,8)$, and the function is known to be affine on $\mathbb R$. Find its formula and explain which extra assumption makes the answer unique.

## Worked answers

1. The formula is $f(x)=(4-x)^2$. Its outputs at $0,1,2,3$ are $16,9,4,1$. Its graph is exactly the four isolated points $(0,16),(1,9),(2,4),(3,1)$. Connecting them would incorrectly add inputs outside the specified domain.
2. Write $f(x)=mx+b$. The pair $(0,2)$ gives $b=2$. The pair $(1,5)$ then gives $m+2=5$, so $m=3$. The third pair checks $f(2)=6+2=8$. Thus $f(x)=3x+2$. The assumption “affine on $\mathbb R$” restricts the function to two parameters. Without it, adding any multiple of $x(x-1)(x-2)$ would preserve the table while changing other values.
