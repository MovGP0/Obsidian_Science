title: "Function transformations"

> [!TLDR]
> Changes outside a function act on output coordinates, while changes inside its argument act on input coordinates through the inverse change.

## Transform points before sketching

Let $f:D\to\mathbb R$ be a real function. For real parameters $a,b,h,k$ with $a\ne0$ and $b\ne0$, define

$$
g(x)=a f\bigl(b(x-h)\bigr)+k.
$$

The most reliable way to interpret this formula is to map a point of the original graph. Suppose $(u,v)$ lies on $f$, so $v=f(u)$. To make the new function use the same input $u$, solve $b(x-h)=u$. Then $x=h+u/b$, and $g(x)=av+k$. Thus the point transformation is

$$
(u,v)\longmapsto\left(h+\frac{u}{b},\ k+av\right).
$$

The horizontal coordinate is scaled by $1/b$ and then translated by $h$. The vertical coordinate is scaled by $a$ and then translated by $k$. This derivation explains why a larger positive coefficient inside the argument compresses the graph horizontally.

## Translations, scales, and reflections

The rule $f(x-h)$ moves a graph right by $h$ if $h>0$. A point formerly at input $u$ moves to $u+h$. The rule $f(x)+k$ moves it upward by $k$ if $k>0$. Negative values move in the opposite direction.

The rule $a f(x)$ scales every height by $a$. For $a>1$, distances from the horizontal axis grow; for $0<a<1$, they shrink. If $a<0$, the sign also reflects the graph across the horizontal axis. The rule $f(bx)$ scales horizontal distances by $1/|b|$. If $b<0$, it also reflects the graph across the vertical axis. Translations are applied after these coordinate scales in the displayed point formula.

Order matters. The expressions $2f(x)+3$ and $2(f(x)+3)$ differ: the second equals $2f(x)+6$. Likewise, $f(2(x-1))$ shifts the horizontally compressed graph right by $1$, whereas $f(2x-1)=f(2(x-1/2))$ shifts it right by $1/2$.

## Domain and range move as well

The new domain consists of inputs for which the inner argument belongs to $D$:

$$
D_g=\{x:b(x-h)\in D\}=\{h+u/b:u\in D\}.
$$

If $R=f(D)$ is the original range, the new range is $\{k+av:v\in R\}$. For a negative scale, interval endpoint order reverses before the endpoints are written from smallest to largest. Endpoint inclusion is preserved under these nonzero affine changes. If $a=0$, the rule can become constant on its inherited domain, so the nonzero assumption is needed for the usual range-scaling statements. The case $b=0$ similarly loses a meaningful horizontal scale.

## Worked example: a transformed parabola

Start with $f(u)=u^2$ on $\mathbb R$, and set

$$
g(x)=-2f\left(\frac{x-1}{2}\right)+3
=-\frac12(x-1)^2+3.
$$

Here $a=-2$, $b=1/2$, $h=1$, and $k=3$. The point map is $(u,v)\mapsto(1+2u,3-2v)$. The old vertex $(0,0)$ becomes $(1,3)$. The points $(-1,1)$ and $(1,1)$ become $(-1,1)$ and $(3,1)$. The points $(-2,4)$ and $(2,4)$ become $(-3,-5)$ and $(5,-5)$.

![[math-03-parabola-transform.svg|**Fig. 03.4** Coordinate mapping turns the original parabola into a wider downward parabola with vertex at (1, 3).]]

The original range is $[0,\infty)$. Multiplication by $-2$ gives $(-\infty,0]$, and addition of $3$ gives $(-\infty,3]$. The domain remains all real numbers. To find the new zeros exactly, solve $-(x-1)^2/2+3=0$. Thus $(x-1)^2=6$, so $x=1\pm\sqrt6$. Transformed points help draw the curve; the formula supplies exact intercepts that a sketch may only estimate.

## Practice

1. Let $f(u)=\sqrt u$ on $[0,\infty)$. Find the domain, range, and image of $(4,2)$ for $g(x)=3f(2(x+1))-5$.
2. Write a formula obtained by reflecting $f$ across the vertical axis, shifting that reflected graph right by $2$, and then shifting it down by $1$.

## Worked answers

1. Here $a=3$, $b=2$, $h=-1$, and $k=-5$. The domain requires $2(x+1)\geq0$, so $x\geq-1$. The range is $[-5,\infty)$. The point map sends $(4,2)$ to $(-1+4/2,-5+3\cdot2)=(1,1)$. Direct substitution gives $g(1)=3\sqrt4-5=1$.
2. Reflection gives $r(x)=f(-x)$. Shift this function right by $2$ to obtain $r(x-2)=f(-(x-2))$. The final formula is $g(x)=f(2-x)-1$. The argument $2-x$ includes the reflection and the shift in the specified order.
