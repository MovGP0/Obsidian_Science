> [!TLDR]
> A function graph records input–output pairs and shows zeros, signs, order, symmetry, and end behaviour.

## What a graph represents

For a real function $f:D\to\mathbb R$, its **graph** is the set

$$
G_f=\{(x,f(x)):x\in D\}.
$$

The horizontal coordinate is the input, and the vertical coordinate is the output. Every allowed input has exactly one point above it. This is the vertical-line test: a vertical line cannot meet a function graph at two different heights. A circle fails this test when considered as a proposed graph of $y$ as a function of $x$.

An **$x$-intercept** has the form $(a,0)$, where $f(a)=0$. Such an input $a$ is a zero or root. A **$y$-intercept** is $(0,f(0))$ and exists only if $0\in D$. A positive function value puts the graph above the horizontal axis. A negative value puts it below that axis. The sign of $f(x)$ and the sign of $x$ are different questions.

## Order and symmetry

The function is **strictly increasing** on an interval $I$ if $a<b$ in $I$ always implies $f(a)<f(b)$. It is **strictly decreasing** there if $f(a)>f(b)$. Replace the output inequalities by $\leq$ or $\geq$ for nondecreasing or nonincreasing behaviour. A curve above the axis can decrease, and a curve below it can increase.

When the domain is symmetric about zero, $f$ is **even** if $f(-x)=f(x)$ for all inputs. Its graph then has reflection symmetry about the vertical axis. It is **odd** if $f(-x)=-f(x)$; the graph then has half-turn symmetry about the origin. Without a symmetric domain, these tests do not define evenness or oddness on all inputs. A function can be neither. The zero function is both.

## Worked example: a parabola without calculus

Let $f(x)=x^2-4$ on $\mathbb R$. To find its zeros, factor:

$$
x^2-4=(x-2)(x+2)=0.
$$

Therefore the $x$-intercepts are $(-2,0)$ and $(2,0)$. The $y$-intercept is $(0,-4)$. Since $x^2<4$ exactly when $-2<x<2$, the graph is below the horizontal axis on $(-2,2)$ and above it on $(-\infty,-2)\cup(2,\infty)$.

To prove monotonic behaviour, choose any $a<b$ and calculate the output difference:

$$
f(b)-f(a)=b^2-a^2=(b-a)(b+a).
$$

For $0\leq a<b$, both factors are positive, so the difference is positive. Thus $f$ is strictly increasing on $[0,\infty)$. For $a<b\leq0$, the first factor is positive and $b+a<0$, so the difference is negative. Thus $f$ is strictly decreasing on $(-\infty,0]$. Its minimum is $-4$, attained at $x=0$.

Finally, $f(-x)=(-x)^2-4=f(x)$, so the function is even. As $x$ becomes large in either direction, $x^2$ becomes arbitrarily large. In limit notation,

$$
\lim_{x\to\infty}f(x)=\infty,
\qquad
\lim_{x\to-\infty}f(x)=\infty.
$$

## Practice

1. For $g(x)=3-x$ on $\mathbb R$, find both intercepts, its sign intervals, its monotonic behaviour, and its two ends.
2. For $h(x)=x^3$ on $\mathbb R$, test parity and prove that the function is strictly increasing.

## Worked answers

1. Setting $3-x=0$ gives the intercept $(3,0)$. Also $g(0)=3$, giving $(0,3)$. The value is positive for $x<3$ and negative for $x>3$. If $a<b$, then $g(b)-g(a)=-(b-a)<0$, so it decreases on all of $\mathbb R$. As $x\to\infty$, $g(x)\to-\infty$; as $x\to-\infty$, $g(x)\to\infty$.
2. Since $h(-x)=-x^3=-h(x)$, the function is odd. If $a<b$, then $b^3-a^3=(b-a)(a^2+ab+b^2)$. The first factor is positive. The second equals $(a+b/2)^2+3b^2/4$ and can vanish only when $a=b=0$, which is excluded. The difference is therefore positive for every $a<b$.
