> [!TLDR]
> A function assigns exactly one output to each input in its domain; its codomain and its actual range can be different sets.

## Inputs, outputs, and specified sets

A **function** $f:A\to B$ assigns exactly one element $f(x)$ of the set $B$ to every element $x$ of the set $A$. The set $A$ is the **domain**. The set $B$ is the **codomain**. The notation $x\mapsto f(x)$ describes the assignment. The expression $f(x)$ means the value of $f$ at $x$; it does not mean multiplication of $f$ by $x$.

The **range**, also called the image of $A$, is

$$
f(A)=\{f(x):x\in A\}\subseteq B.
$$

The codomain states which outputs are permitted. The range states which outputs actually occur. For $f:\mathbb R\to\mathbb R$ given by $f(x)=x^2$, the domain and codomain are both the real numbers, but the range is $[0,\infty)$. Squares are nonnegative. Conversely, each $y\geq0$ occurs because $f(\sqrt y)=y$. Both parts are needed to prove the claimed range.

A formula alone does not always specify a function completely. The rules $x\mapsto x^2$ on $\mathbb R$ and on $[0,\infty)$ have different domains. They therefore define different functions. Changing the codomain also changes the specified mapping, even when the formula and graph stay the same. This matters when a function must have an inverse; see [[03.07 Composition and inverse functions]].

## Natural domains and evaluation

If a real formula is given without a domain, its **natural real domain** usually means all real inputs for which the formula is defined. A denominator cannot be zero. The radicand of a real square root must be nonnegative. A real logarithm needs a positive argument. These conditions apply together, not separately as alternative choices.

For example, consider

$$
h(x)=\frac{\sqrt{x+2}}{x-1}.
$$

The square root requires $x+2\geq0$, so $x\geq-2$. The denominator requires $x\ne1$. Thus its natural domain is $[-2,1)\cup(1,\infty)$. Evaluation means substitute an allowed input and then calculate:

$$
h(2)=\frac{\sqrt{2+2}}{2-1}=\frac2{1}=2.
$$

The expression $h(1)$ is undefined. It is not infinity, and it is not zero. An infinite limit, where one exists, is a statement about nearby inputs rather than a function value.

## Piecewise rules and a worked example

A piecewise rule uses different expressions on different parts of the domain. Consider $p:\mathbb R\to\mathbb R$ with

$$
p(x)=
\begin{cases}
-x,&x<0,\\
x+1,&0\leq x\leq2,\\
5,&x>2.
\end{cases}
$$

To calculate $p(-3)$, first test the input against the conditions. Since $-3<0$, use the first expression: $p(-3)=-(-3)=3$. Since $0$ belongs to the middle interval, $p(0)=0+1=1$. At the other boundary, $p(2)=2+1=3$. For $p(4)$, use the last expression and obtain $5$.

To determine its range, examine each branch. For $x<0$, the value $-x$ runs through $(0,\infty)$. The middle branch contributes $[1,3]$. The last branch contributes the single value $5$. Their union is $(0,\infty)$, since the first branch already contains the other outputs. Zero is not attained: $x=0$ uses the middle rule, not the first rule.

Branch conditions must cover the proposed domain. If two conditions overlap, their expressions must agree on that overlap, or the rule gives two outputs and fails to define a function. Different inputs may have the same output; that does not violate the definition.

## Practice

1. Give the natural real domain of $q(x)=\sqrt{5-x}/(x+2)$ and calculate $q(1)$.
2. Let $s:[-2,3]\to\mathbb R$ have rule $s(x)=x^2$. Find its range, and explain whether the value $9$ occurs at one or two inputs in this domain.

## Worked answers

1. The square root requires $5-x\geq0$, which is $x\leq5$. The denominator excludes $x=-2$. The domain is $(-\infty,-2)\cup(-2,5]$. At $x=1$, $q(1)=\sqrt4/3=2/3$.
2. All squares are nonnegative, and $s(0)=0$. On the given interval, $|x|\leq3$, so $s(x)\leq9$. Every $y\in[0,9]$ occurs at $x=\sqrt y\in[0,3]$. Hence the range is $[0,9]$. Solving $x^2=9$ gives $x=\pm3$, but only $3$ belongs to $[-2,3]$. Thus $9$ occurs at exactly one allowed input.
