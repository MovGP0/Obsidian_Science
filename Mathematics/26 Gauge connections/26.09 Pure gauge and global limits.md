title: "Pure gauge and global limits"

> [!TLDR]
> Zero curvature permits a connection to be removed locally, but a global removal also requires compatible transport around all loops.

## Local removal and flatness

Assume the base is a smooth Hausdorff, second-countable manifold. Use $D=d+A$ and the passive frame change $e'=eg$, with

$$
A'=g^{-1}Ag+g^{-1}dg.
$$

A connection form is **pure gauge on a domain** if a smooth single-valued allowed frame change on that domain makes $A'=0$. Equivalently, in an initial trivialization it has the form $A=h^{-1}dh$ for a smooth group-valued map $h$: choosing $g=h^{-1}$ gives zero. The domain is part of this statement.

A connection is **flat** when its curvature $F=dA+A\wedge A$ vanishes. If $A$ can be removed, then $F=0$ there, because curvature transforms by conjugation. Conversely, a smooth flat connection can be removed on a sufficiently small contractible open set. One constructs a parallel frame by transporting a basis from one point. Flatness makes transport independent of small deformations of the path. On a simply connected domain, these deformations relate all paths with the same endpoints, so the parallel frame is globally well defined.

For a connected base, a flat connection admits a global parallel frame precisely when all its loop holonomies are the identity. This criterion also constructs a trivialization of the bundle. A bundle that is already trivial can still carry a connection with nonidentity holonomy. Bundle triviality and triviality of a particular connection are different claims.

## Worked example: a flat connection around a missing point

Let $M=\mathbb R^2\setminus\{(0,0)\}$ and take a trivial complex line bundle with $D=d+ia$. For a real constant $\alpha$, define the globally smooth one-form

$$
a=\alpha\frac{-y\,dx+x\,dy}{x^2+y^2}.
$$

On any patch with a smooth polar angle $\theta$, this is $a=\alpha\,d\theta$. Therefore $da=\alpha d^2\theta=0$ locally, and hence everywhere on $M$. The connection is flat. On such a patch, choose the phase $\chi=-\alpha\theta$; then $a'=a+d\chi=0$.

For the unit circle $\gamma(t)=(\cos t,\sin t)$, $0\le t\le2\pi$, substitution gives

$$
-y\,dx+x\,dy=(\sin^2t+\cos^2t)dt=dt,
\qquad
\oint_\gamma a=2\pi\alpha.
$$

Thus the holonomy is $H_\gamma=e^{-2\pi i\alpha}$. If $\alpha=1/2$, it is $-1$. A frame that made the connection zero globally would give identity transport around every loop, which contradicts this result. Local removal does not extend to global removal.

## A global phase need not have a global real angle

If $\alpha=n\in\mathbb Z$, the function

$$
g=e^{-in\theta}
=\left(\frac{x-iy}{\sqrt{x^2+y^2}}\right)^n
$$

is single-valued and smooth on the punctured plane. Negative integers use the reciprocal, which exists because the modulus is one. This $g$ removes $a$, although a single real-valued $\theta$ does not exist globally. After a full turn, $g$ gains the factor $e^{-2\pi in}=1$. For noninteger $\alpha$, that factor is not one. Hence this family is globally removable exactly when $\alpha$ is an integer.

There is no conflict with Stokes' theorem: the disk bounded by the unit circle contains the removed point and is not a surface in $M$. One cannot integrate $da=0$ over that disk as if the connection were defined throughout it.

For the local flatness theorem and its extension to a simply connected base, see Kobayashi and Nomizu, *Foundations of Differential Geometry*, volume I, Chapter II, §9 ([flat connections excerpt](https://users.math.msu.edu/users/parker/GT/Kobayashi-Nomizu.pdf)). The transport construction above gives the geometric reason for those statements.

## Practice

1. On $\mathbb R^2$, let $a=d(xy)$. Find a global unitary frame change that removes the connection.
2. For the punctured-plane family, compare $\alpha=3$ and $\alpha=1/3$. What changes if the domain is restricted to the plane minus the nonpositive horizontal ray?

## Worked answers

1. Take $\chi=-xy$ and $g=e^{-ixy}$. This is smooth and single-valued on all of $\mathbb R^2$. Then $a'=d(xy)+d(-xy)=0$. Every loop integral of $a$ is zero because $xy$ is a global potential.
2. For $\alpha=3$, $H=e^{-6\pi i}=1$ and the global function $g=e^{-3i\theta}$ removes the connection. For $\alpha=1/3$, $H=e^{-2\pi i/3}\ne1$, so no global removal exists on the punctured plane. On the smaller cut domain, choose $-\pi<\theta<\pi$. This is a smooth real angle there, so $g=e^{-i\alpha\theta}$ removes the connection for either value. Restricting the domain removed the obstructing loops.
