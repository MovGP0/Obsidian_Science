title: "Local gauge transformations"
---

> [!TLDR]
> A local gauge transformation changes the basis in each fibre smoothly, while a coordinate change changes the labels of base points.

## Two different choices

Let $E\to M$ be a rank-$r$ vector bundle. On an open set $U$, write a section as $s=e\psi$, where $e=(e_1,\ldots,e_r)$ is a frame and $\psi$ is a component column. A **local gauge transformation** in the frame convention used here is a smooth map $g:U\to G$, where $G$ is the allowed group of invertible frame matrices. It acts by

$$
e'=eg,\qquad \psi'=g^{-1}\psi.
$$

The point $p\in U$ and the vector $s(p)$ stay fixed. Only the basis used to describe that vector changes. This is a passive frame change. Some texts use the term gauge transformation for an active bundle automorphism. The formulas below specify the passive convention, so there is no need to infer a sign from terminology.

If no fibre metric is specified, take $G=\operatorname{GL}(r,\mathbb R)$ or $\operatorname{GL}(r,\mathbb C)$. For orthonormal real frames, take $G=O(r)$. For orthonormal complex frames, take $G=U(r)$. Smoothness matters: a derivative of $g$ will occur when sections are differentiated.

## A coordinate change on the base

Let $x=(x^1,\ldots,x^n)$ and $y=(y^1,\ldots,y^n)$ be coordinate systems on the same open set. Keeping the frame fixed gives component functions related by composition:

$$
\psi_y(y)=\psi_x(x(y)).
$$

There is no extra $r\times r$ matrix in this equation. A coordinate change tells us how to locate the point; a frame change tells us how to express a vector above it. The dimensions $n$ and $r$ can differ.

A one-form $A=A_i^x\,dx^i$ also changes its coordinate coefficients:

$$
A_j^y=\sum_i A_i^x\frac{\partial x^i}{\partial y^j}.
$$

Here the entries of $A_i^x$ can themselves be matrices. A gauge transformation acts on those fibre matrices, while this Jacobian acts on the base one-form index. For tangent bundles, a coordinate basis is tied to coordinates, so a coordinate change induces a particular frame change. This special relation does not make the two choices identical for an arbitrary vector bundle.

## Worked example: a moving rotation

Consider $E=\mathbb R\times\mathbb R^2$ over the base coordinate $x$. Let the old frame be constant and take

$$
\psi(x)=\begin{pmatrix}1\\0\end{pmatrix},\qquad
g(x)=R(x)=\begin{pmatrix}\cos x&-\sin x\\\sin x&\cos x\end{pmatrix}.
$$

The transformed components are

$$
\psi'(x)=R(-x)\psi(x)=\begin{pmatrix}\cos x\\-\sin x\end{pmatrix}.
$$

Although these components vary, $e'(x)\psi'(x)=e\psi(x)$ is the same constant geometric section. The local rotation changes the description at each point, not the section.

Now change the base coordinate to $y=2x$, with no further frame change. Then

$$
\psi'_y(y)=\begin{pmatrix}\cos(y/2)\\-\sin(y/2)\end{pmatrix}.
$$

The angle at a given point has not changed: it is now expressed as a function of $y$. This composition step is distinct from multiplication by $R(-x)$.

## Composition and limits

If $e'=eg$ and $e''=e'h$, then $e''=e(gh)$. Components transform as $\psi''=h^{-1}g^{-1}\psi=(gh)^{-1}\psi$. Matrix order matters. A constant $g$ changes the frame uniformly; a variable $g$ can create derivative terms, as shown in [[26.03 The derivative problem]]. A local gauge function need not extend to all of $M$.

## Practice

1. In a complex line, use $g(x)=e^{ix^2}$ and $\psi(x)=x+i$. Find the transformed components in the base coordinate $y=3x$.
2. Let $g=\begin{pmatrix}1&1\\0&1\end{pmatrix}$ and $h=\operatorname{diag}(2,1)$. Find the total frame matrix after first $g$, then $h$.

## Worked answers

1. First change the frame: $\psi'(x)=e^{-ix^2}(x+i)$. Then substitute $x=y/3$: $\psi'_y(y)=e^{-iy^2/9}(y/3+i)$. The exponential comes from the fibre basis; the substitutions come from the base coordinates.
2. The total matrix is $gh=\begin{pmatrix}2&1\\0&1\end{pmatrix}$. Its inverse is $h^{-1}g^{-1}=\begin{pmatrix}1/2&-1/2\\0&1\end{pmatrix}$. Reversing the order would give $hg=\begin{pmatrix}2&2\\0&1\end{pmatrix}$, a different frame.
