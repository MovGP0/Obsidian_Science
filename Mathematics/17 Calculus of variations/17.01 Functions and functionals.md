title: "Functions and functionals"
---

> [!TLDR]
> A function maps an input to an output; a functional takes an entire function as its input and returns a scalar.

## Two levels of input

A real function $y:[0,1]\to\mathbb R$ assigns the number $y(x)$ to each number $x$ in its domain. For example, $y(x)=x^2$ is a pointwise rule. The symbol $y$ denotes the whole rule, while $y(x)$ denotes one of its values. This distinction becomes essential when the input to another map is itself a function.

Let $X$ be a set of functions. A **functional** is a map $J:X\to\mathbb R$ (or to $\mathbb C$ when complex scalars are used). For example, take $X=C^1([0,1])$, the space of continuously differentiable real functions. Then

$$
J[y]=\int_0^1 y(x)^2\,dx,
\qquad K[y]=\int_0^1 y'(x)^2\,dx
$$

are functionals on $X$. Square brackets emphasize that the input is $y$, although ordinary parentheses are also valid notation. The variable $x$ is a bound integration variable: after integration, $J[y]$ is one number and does not depend on $x$.

A functional is still a function in the broad set-theoretic meaning of that word. The special name identifies its function-valued input. An evaluation functional $E_c[y]=y(c)$, where $c\in[0,1]$ is fixed, is also a functional. It uses one value of the input function. Thus, a functional can depend on a whole curve, but it need not use every point of that curve.

## The domain is part of the problem

The expression for $J$ does not specify the admissible inputs by itself. The same integral can be studied on all of $C^1([0,1])$, or only on

$$
\mathcal A=\{y\in C^1([0,1]):y(0)=0,\ y(1)=1\}.
$$

The set $\mathcal A$ is an affine set rather than a vector space: the sum of two members has final value $2$. Changing the domain can change the minimizer even if the formula stays the same. For instance, $K[y]\geq0$ has every constant function as a minimizer on $X$. On $\mathcal A$, the unique minimizer is $y(x)=x$.

To verify the latter claim, write $y=x+h$, where $h(0)=h(1)=0$. Then

$$
K[x+h]=\int_0^1(1+h')^2\,dx
=1+2[h]_0^1+\int_0^1h'^2\,dx
=1+\int_0^1h'^2\,dx.
$$

Equality requires $h'=0$ everywhere. Since $h(0)=0$, this gives $h=0$. This calculation compares complete input functions, not individual values $y(x)$.

## Worked example: same endpoint, different functionals

Let $y_1(x)=x$ and $y_2(x)=x^2$. Both lie in $\mathcal A$ and satisfy $E_1[y_1]=E_1[y_2]=1$. However,

$$
J[y_1]=\int_0^1x^2\,dx=\frac13,
\qquad J[y_2]=\int_0^1x^4\,dx=\frac15.
$$

Their derivative integrals give the opposite ordering:

$$
K[y_1]=\int_0^1 1\,dx=1,
\qquad K[y_2]=\int_0^1(2x)^2\,dx=\frac43.
$$

There is no conflict. The two functionals measure different features. An endpoint value cannot determine either integral, and one integral cannot generally determine the other.

A functional can also take a function of several variables as input. On a domain $\Omega\subset\mathbb R^n$, an example is $J[u]=\int_\Omega u(\mathbf x)^2\,d\mathbf x$. The entire scalar field $u$ is the argument. More general examples appear in [[17.06 Several variables and fields]].

## Common errors

Do not confuse $J[y]$ with the integrand $y(x)^2$, and do not treat $J$ as a function of the dummy variable $x$. State the function class and restrictions before asking for an extremum. Finally, $J[y+z]=J[y]+J[z]$ is not true for the square integral: the extra term is $2\int_0^1yz\,dx$.

## Practice

1. For $y_a(x)=ax$ with $a\in\mathbb R$, calculate $J[y_a]$ and $K[y_a]$. Which values of $a$ make $y_a$ a member of $\mathcal A$?
2. Compare $P[y]=(\int_0^1y\,dx)^2$ with $J[y]=\int_0^1y^2\,dx$ for $y(x)=2x-1$. Explain why the placement of the square matters.

### Worked answers

1. Substitution gives $J[y_a]=a^2\int_0^1x^2\,dx=a^2/3$. Since $y_a'=a$, $K[y_a]=a^2$. The initial endpoint is always zero, but the final endpoint is $a$. Thus, only $a=1$ belongs to $\mathcal A$.
2. The integral of $2x-1$ is $[x^2-x]_0^1=0$, so $P[y]=0$. In contrast, $J[y]=\int_0^1(4x^2-4x+1)\,dx=4/3-2+1=1/3$. Positive and negative values cancel before the square in $P$; they cannot cancel in the nonnegative integrand of $J$.
