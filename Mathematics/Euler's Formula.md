## Exponential notation of [[Complex Numbers]]

Using **Euler's Formula** we get an alternative notation for [[Complex Numbers]]:
$$e^{iθ} = \cosθ + i\sinθ$$
[![obsidian|300](https://upload.wikimedia.org/wikipedia/commons/7/71/Euler%27s_formula.svg)]

## Multiplication of Complex Numbers using Exponential notation
 
For multiplication we get the relation:
$$e^{iθ} e^{iφ} = e^{iθ + iφ} = e^{i(θ + φ)} = \cos(θ + φ) + i \sin(θ + φ)$$

## Important Values

No rotation
$$e^{i 0} = 1$$

Rotation by 45°
$$e^{i\frac{\pi}{4}} = \frac{1}{\sqrt{2}} + \frac{i}{\sqrt{2}} = \frac{1}{\sqrt{2}} (1+i)$$

Rotation by 90°
$$e^{i\frac{\pi}{2}} = i$$

Rotation by 180°
$$e^{i\pi} = -1$$

Rotation by 270°
$$e^{i \frac{3\pi}{2}} = -i$$

Rotation by 360°
$$e^{i2\pi} = 1$$

> [!note]
> The +/- depends on the chosen coordinate system.
