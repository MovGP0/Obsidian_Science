> [!TLDR]
> A set collects objects; membership and set operations state which objects belong to each collection.

## Objects and membership

A **set** is a collection of distinct objects, called its elements. The expression $x\in A$ says that the object named $x$ belongs to the set named $A$. The expression $x\notin A$ says that it does not. Braces list the elements of a finite set: $A=\{1,2,4\}$. Their order does not matter, and repetition adds nothing. Thus $\{1,2,4\}=\{4,1,2,2\}$.

An element and a set that contains it are different objects. For $A=\{1,2,4\}$, the statement $2\in A$ is true. The statement $\{2\}\subseteq A$ is also true, but it says something different: every element of the one-element set $\{2\}$ belongs to $A$. In this example, $\{2\}\in A$ is false, because none of the three listed elements is a set.

Set-builder notation describes a set by a condition. For example,

$$
E=\{n\in\mathbb Z: n=2k\text{ for some }k\in\mathbb Z\}
$$

is the set of even integers. The colon means “such that.” The expression first states the domain $\mathbb Z$, then gives the membership condition. A set can be infinite without having a final listed element.

## Standard number sets

This article uses $\mathbb N=\{0,1,2,\ldots\}$ for the natural numbers. Some books start $\mathbb N$ at $1$, so always check that convention. The integers $\mathbb Z$ also include negative whole numbers. The rational numbers are

$$
\mathbb Q=\{p/q:p,q\in\mathbb Z,\ q\ne0\}.
$$

The real numbers $\mathbb R$ include the rationals and numbers such as $\sqrt2$ that cannot be written as such a fraction. The complex numbers have the form $a+bi$, where $a,b\in\mathbb R$ and $i^2=-1$. They form $\mathbb C$. These sets satisfy

$$
\mathbb N\subsetneq\mathbb Z\subsetneq\mathbb Q\subsetneq\mathbb R\subsetneq\mathbb C.
$$

The symbol $\subsetneq$ means a proper subset: the set on the left is contained in, but unequal to, the set on the right. Each inclusion is strict. For example, $-1$, $1/2$, $\sqrt2$, and $i$ provide an element added at the respective stages. Standard number systems identify a real $a$ with the complex number $a+0i$.

## Subsets and set operations

The statement $A\subseteq B$ means that every element of $A$ belongs to $B$. Equality requires both inclusions: $A=B$ exactly when $A\subseteq B$ and $B\subseteq A$. The empty set $\varnothing$ has no elements and is a subset of every set. No element can violate its subset condition.

For sets $A$ and $B$, their union $A\cup B$ contains objects in at least one set. Their intersection $A\cap B$ contains objects in both sets. Their difference $A\setminus B$ contains objects in $A$ that are not in $B$. A complement needs a stated universe $U$: $A^{\mathrm c}=U\setminus A$. Without a universe, “everything outside $A$” has no fixed meaning.

## Worked example: compute and check

Let $U=\{1,2,3,4,5,6,7,8\}$, $A=\{1,2,4,8\}$, and $B=\{2,3,4,6\}$. List each object once to obtain

$$
\begin{aligned}
A\cup B&=\{1,2,3,4,6,8\},\\
A\cap B&=\{2,4\},\\
A\setminus B&=\{1,8\},\\
A^{\mathrm c}&=\{3,5,6,7\}.
\end{aligned}
$$

The intersection has two elements, both present in each input list. The difference removes those two elements from $A$. Because $1\in A$ but $1\notin B$, $A$ is not a subset of $B$. For a finite set, $|A|$ denotes its number of elements. Here

$$
|A\cup B|=|A|+|B|-|A\cap B|=4+4-2=6.
$$

The subtraction corrects the double count of the shared elements.

## Practice

1. Let $C=\{-2,0,2\}$ and $D=\{0,1,2,3\}$. Find their union, intersection, and $D\setminus C$. Is $C\subseteq D$?
2. Classify $-3$, $0.125$, $\sqrt9$, and $\sqrt2$ in the smallest set among $\mathbb N,\mathbb Z,\mathbb Q,\mathbb R$ that contains each number. Use this article's convention for $\mathbb N$.

> [!example]- Worked answers
> 1. The union combines the lists without repetition, so $C\cup D=\{-2,0,1,2,3\}$. Their shared elements give $C\cap D=\{0,2\}$. Remove $0$ and $2$ from $D$ to get $D\setminus C=\{1,3\}$. The inclusion fails because $-2\in C$ and $-2\notin D$.
>
> 2. The number $-3$ is an integer but not natural. Since $0.125=125/1000=1/8$, it is rational but not an integer. The square-root symbol denotes the nonnegative root, so $\sqrt9=3\in\mathbb N$. The number $\sqrt2$ is real and irrational, so its smallest listed set is $\mathbb R$.

The precise logic of “every element” is developed in [[01.05 Quantifiers]].
