> [!TLDR]
> A function assigns exactly one output to every input in its domain; its codomain specifies where those outputs are allowed to lie.

## Relations and ordered pairs

For sets $A$ and $B$, their Cartesian product $A\times B$ consists of ordered pairs $(a,b)$ with $a\in A$ and $b\in B$. Order matters: $(1,2)$ and $(2,1)$ are different pairs. A **relation from $A$ to $B$** is a subset $R\subseteq A\times B$. It records which inputs and outputs are associated. We write $aRb$ when $(a,b)\in R$.

A relation need not assign any output to a given input, and it can assign several. For example, $R=\{(1,1),(1,2),(2,2)\}$ relates $1$ to two outputs. It therefore does not define a function on $\{1,2\}$. The relation “is less than” on integers is another relation with many possible second entries.

## What makes a function

A **function** $f:A\to B$ assigns exactly one element $f(a)\in B$ to each $a\in A$. The set $A$ is its **domain**. The set $B$ is its **codomain**. The notation $f(a)$ names the output at input $a$; it does not mean multiplication of $f$ and $a$. The function $f$ is the complete assignment, whereas $f(a)$ is one of its values.

Two conditions are essential: every input in $A$ has an output, and that output is unique. Different inputs can have the same output. There is no requirement that each member of $B$ be used. The **image** or range is the set of actual outputs:

$$
f(A)=\{f(a):a\in A\}\subseteq B.
$$

In the diagram, $f(1)=1$, $f(2)=4$, and $f(3)=4$. The output $9$ belongs to the codomain but not the image. A missing arrow from a domain element would prevent the diagram from defining a function on that domain. Two arrows from a single input to different outputs would also fail.

## Formulas need domains

A formula is one way to specify a function, but the formula alone need not give the whole specification. The function $s:\mathbb R\to\mathbb R$ with $s(x)=x^2$ has image $[0,\infty)$. The function $t:[0,\infty)\to[0,\infty)$ with $t(x)=x^2$ uses the same formula but a different domain and codomain. Its inputs and the properties of its assignment differ.

A function is **injective** if equal outputs require equal inputs. It is **surjective** if its image equals its codomain. It is **bijective** if both conditions hold. The real square function $s$ is not injective because $s(-2)=s(2)$. It is not surjective onto $\mathbb R$ because no real square is negative. The restricted function $t$ is bijective: each nonnegative $y$ has the unique nonnegative preimage $\sqrt y$.

Division imposes a domain condition. The formula $r(x)=1/(x-2)$ does not define a function on all of $\mathbb R$. It defines one on $\mathbb R\setminus\{2\}$ with real codomain. A function can also be defined by cases, a table, or an algorithm; a single algebraic formula is not required.

## Worked example: a finite function

Let $A=\{-2,-1,0,1,2\}$, $B=\{0,1,2,3,4\}$, and $f:A\to B$ be given by $f(x)=x^2$. Compute the outputs individually:

$$
\begin{aligned}
f(-2)&=4,& f(-1)&=1,& f(0)&=0,\\
f(1)&=1,& f(2)&=4.
\end{aligned}
$$

Thus $f(A)=\{0,1,4\}$. The function is well defined because each squared input gives one member of $B$. It is not injective, since $-1\ne1$ but their outputs agree. It is not surjective because $2$ and $3$ are not outputs. To solve $f(x)=1$ within the domain, inspect the allowed inputs: $x=-1$ or $x=1$. A function value is unique for each input, but an equation about its output can have more than one input solution.

## Practice

1. Let $A=\{a,b,c\}$ and $B=\{0,1\}$. Which relation is a function from $A$ to $B$: $R_1=\{(a,0),(b,0),(c,1)\}$ or $R_2=\{(a,0),(a,1),(b,0)\}$? Explain both required conditions.
2. For $g:\mathbb R\setminus\{1\}\to\mathbb R$ with $g(x)=(x+1)/(x-1)$, compute $g(3)$ and solve $g(x)=1$.

> [!example]- Worked answers
> 1. In $R_1$, each of $a,b,c$ appears once as an input, so every input has exactly one output. It is a function. In $R_2$, $a$ has two distinct outputs and $c$ has none. Each defect separately prevents $R_2$ from defining a function on $A$.
>
> 2. Substitution gives $g(3)=4/2=2$. To solve $g(x)=1$, use $x\ne1$ to multiply by $x-1$. This gives $x+1=x-1$, hence $1=-1$, which is impossible. Thus $1$ is in the codomain but not the image.
