title: "Variables and expressions"

> [!TLDR]
> A variable names an object, an expression specifies a value, and an equation asserts equality between two values.

## Objects and their names

The number $3$ is an object. The symbol $x$ can name that object when we assign $x=3$. A different symbol can name the same object: if $y=3$, then $x=y$. Conversely, a single symbol can refer to different objects in different problems. Names help us reason; they do not create extra numbers.

A **variable** is a symbol whose permitted values belong to a stated domain. In “let $x\in\mathbb R$,” $x$ denotes a real number. In “find an integer $n$,” the domain is $\mathbb Z$. A **constant** has a fixed value within the current discussion. A parameter is held fixed while another variable changes. For example, in $ax+2$, we can treat $a$ as a parameter and $x$ as the input. These roles depend on context; a letter has no permanent role.

An **expression** is a syntactically valid combination of names, numbers, and operations. It denotes a value whenever its operations are defined. For example, $2x+1$ denotes $7$ when $x=3$. It does not assert anything by itself. An **equation**, such as $2x+1=7$, asserts that two expressions have the same value. With an unspecified $x$, it is a condition to test or solve.

## Structure determines meaning

Parentheses specify which operations act together. The expressions $2(x+1)$ and $2x+1$ are generally different. Under the usual order of operations, powers are evaluated before multiplication and division, which precede addition and subtraction. Thus $-x^2$ means $-(x^2)$, whereas $(-x)^2$ squares the negative input. At $x=3$, their values are $-9$ and $9$.

Substitution replaces every free occurrence of a variable by the given expression, with parentheses where needed. If $P(x)=x^2-2x$, then

$$
P(-3)=(-3)^2-2(-3)=9+6=15.
$$

Writing $-3^2-2(-3)$ would omit necessary grouping and change the first term. A good check is to identify the whole input to each operation before calculating.

The domain can restrict an expression. The real expression

$$
E(x)=\frac{x^2-1}{x-1}
$$

requires $x\ne1$, because division by zero is undefined. Factoring gives $E(x)=x+1$ for $x\ne1$. This does not assign a value to the original fraction at $1$. Equivalent formulas must retain the original domain restriction. Square roots over $\mathbb R$ similarly require a nonnegative radicand.

## Equations, identities, and solutions

A solution of an equation is an allowed assignment that makes it true. An identity holds for every assignment in its stated domain. For real $x$, $2(x+1)=2x+2$ is an identity. The equation $2x+1=7$ is true only for $x=3$. Its solution set is $\{3\}$.

To solve an equation, apply operations that preserve exactly its solutions. Adding the same value to both sides is reversible. Multiplying both sides by a known nonzero number is also reversible. Multiplication by a possibly zero expression can lose information; squaring can add solutions. Always state the conditions that make a step reversible.

## Worked example: a rational equation

Solve the following equation over $\mathbb R$:

$$
\frac{x+2}{x-1}=2.
$$

First record $x\ne1$. On this domain we can multiply both sides by $x-1$:

$$
\frac{x+2}{x-1}=2
\iff x+2=2(x-1)
\iff x+2=2x-2
\iff x=4.
$$

The symbol $\iff$ records equivalence: each displayed condition has exactly the same solutions in the allowed domain. Substitution checks the candidate: $(4+2)/(4-1)=6/3=2$. Also $4\ne1$, so the solution set is $\{4\}$. The check confirms both the original equation and its domain condition.

## Practice

1. For $F(t)=3t^2-(t+4)$, evaluate $F(-2)$. Identify the input, the expression, and the resulting object.
2. Solve $\sqrt{x+2}=x$ over the reals. Explain why checking the candidates is necessary.

> [!example]- Worked answers
> 1. The input is $-2$. Substitution gives $F(-2)=3(-2)^2-((-2)+4)=12-2=10$. The expression is $3t^2-(t+4)$ before substitution, and $3(-2)^2-((-2)+4)$ after substitution. Both the latter expression and the numeral $10$ name the same resulting number.
>
> 2. The radical requires $x\ge-2$, and its nonnegative output requires any solution to satisfy $x\ge0$. Squaring gives $x+2=x^2$, hence $(x-2)(x+1)=0$. The candidates are $2$ and $-1$. Substitution gives $\sqrt4=2$ for $2$, but $\sqrt1=1\ne-1$ for $-1$. Squaring lost the sign information. The only solution is $2$.
