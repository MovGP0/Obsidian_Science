title: "Summary Table of Feynman Rules for QED"
---

> [!TLDR]
> The QED rule table combines propagators, vertices, external factors, loop signs, momentum conservation, and symmetry factors.

**Table 7.1** QED Feynman rules in Feynman gauge, ξ = 1. The source takes the positive charge magnitude $\electric{e}>0$ and physical electron charge $-\electric{e}$.

| Element | Factor | Description |
| --- | --- | --- |
| Photon propagator | $\displaystyle\frac{-ig^{\mu\nu}}{\mechanical{k}^{\,2}+i\epsilon}$ | Wavy internal line. |
| Electron propagator | $\displaystyle\frac{i(\not{\mechanical{p}}+\mechanical{m})}{\mechanical{p}^{\,2}-\mechanical{m}^2+i\epsilon}$ | Solid internal line with an arrow. |
| Vertex | $-i\electric{e}\gamma^\mu$ | One photon leg and two fermion legs. |
| Incoming electron | $u^s(\mechanical{p})$ | Incoming fermion state. |
| Outgoing electron | $\bar u^{s'}(\mechanical{p}')$ | Outgoing fermion state. |
| Incoming positron | $\bar v^s(\mechanical{p})$ | Incoming antifermion state. |
| Outgoing positron | $v^{s'}(\mechanical{p}')$ | Outgoing antifermion state. |
| Incoming photon | $\signal{\epsilon}_\mu^\lambda(\mechanical{k})$ | Incoming wavy line. |
| Outgoing photon | $\signal{\epsilon}_\mu^{\lambda'*}(\mechanical{k}')$ | Outgoing wavy line. |
| Four-momentum conservation | $(2\pi)^4\delta^{(4)}(\sum_i\mechanical{p}_i)$ | At each vertex, with all momenta entering. |
| Fermion loop | $(-1)\operatorname{Tr}[\cdots]$ | For each closed fermion loop. |
| Loop momentum | $\displaystyle\int\frac{d^4\mechanical{k}}{(2\pi)^4}$ | For each independent loop. |
| Symmetry factor | $1/S$ | For each graph. |

## Physical quantities

| Symbol | Unit | Quantity | Description |
| --- | --- | --- | --- |
| $\electric{e}$ | $1$ | Electric coupling magnitude | The positive charge parameter in the source convention. |
| $\mechanical{k},\mechanical{k}'$ | $\unit{MeV}$ | Photon and loop momenta | The photon momenta and independent loop integration momentum. |
| $\mechanical{p},\mechanical{p}',\mechanical{p}_i$ | $\unit{MeV}$ | Fermion and vertex momenta | The internal, external, and all-incoming momentum labels. |
| $\mechanical{m}$ | $\unit{MeV}$ | Fermion mass | The mass in the internal Dirac propagator. |
| $u,\bar u,v,\bar v$ | $\unit{MeV^{1/2}}$ | External spinors | The normalized electron and positron spinor factors. |
| $\signal{\epsilon}_\mu^\lambda$ | $1$ | Photon polarization | The normalized external photon polarization factor. |
