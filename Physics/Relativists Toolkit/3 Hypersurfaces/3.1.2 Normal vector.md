> [!TLDR]
> A non-null hypersurface has a unit normal; a null hypersurface has a normal that also follows its geodesic generators.

<!-- PDF page 76; printed page 60 -->

The vector $\Phi_{,\alpha}$ is normal to the hypersurface, because the value of $\Phi$ changes only in the direction orthogonal to $\Sigma$. A *unit normal* $n_\alpha$ can be introduced if the

<!-- PDF page 77; printed page 61 -->

hypersurface is not null. This is defined so that

$$
n^\alpha n_\alpha=\varepsilon\equiv
\begin{cases}-1&\text{if }\Sigma\text{ is spacelike}\\
+1&\text{if }\Sigma\text{ is timelike}\end{cases},
\tag{3.3}
$$

and we demand that $n^\alpha$ point in the direction of increasing $\Phi$: $n^\alpha\Phi_{,\alpha}>0$. It is easy to check that $n_\alpha$ is given by

$$
n_\alpha=\frac{\varepsilon\Phi_{,\alpha}}{|g^{\mu\nu}\Phi_{,\mu}\Phi_{,\nu}|^{1/2}}
\tag{3.4}
$$

if the hypersurface is either spacelike or timelike.

The unit normal is not defined when $\Sigma$ is null, because $g^{\mu\nu}\Phi_{,\mu}\Phi_{,\nu}$ is then equal to zero. In this case we let

$$
\mechanical{k}_\alpha=-\Phi_{,\alpha}
\tag{3.5}
$$

be the normal vector; the sign is chosen so that $\mechanical{k}^\alpha$ is future-directed when $\Phi$ increases toward the future. Because $\mechanical{k}^\alpha$ is orthogonal to itself $(\mechanical{k}^\alpha\mechanical{k}_\alpha=0)$, this vector is also *tangent* to the null hypersurface $\Sigma$ (Fig. 3.2). In fact, by computing $\mechanical{k}^\alpha{}_{;\beta}\mechanical{k}^\beta$ and showing that it is proportional to $\mechanical{k}^\alpha$, we can prove that $\mechanical{k}^\alpha$ is tangent to null geodesics contained in $\Sigma$. We have $\mechanical{k}_{\alpha;\beta}\mechanical{k}^\beta=\Phi_{;\alpha\beta}\Phi^{,\beta}=\Phi_{;\beta\alpha}\Phi^{,\beta}=\tfrac12(\Phi_{,\beta}\Phi^{,\beta})_{;\alpha}$; because $\Phi_{,\beta}\Phi^{,\beta}$ is zero everywhere on $\Sigma$, its gradient must be directed along $\mechanical{k}_\alpha$, and we have that $(\Phi_{,\beta}\Phi^{,\beta})_{;\alpha}=2\mechanical{\kappa}\mechanical{k}_\alpha$ for some scalar $\mechanical{\kappa}$. We have found that the normal vector satisfies

$$
\mechanical{k}^\alpha{}_{;\beta}\mechanical{k}^\beta
=\mechanical{\kappa}\mechanical{k}^\alpha,
$$

the general form of the geodesic equation. The hypersurface is therefore generated by null geodesics, and $\mechanical{k}^\alpha$ is tangent to the generators. The geodesics are parameterized by $\mechanical{\lambda}$, so that a displacement along each generator is described by $dx^\alpha=\mechanical{k}^\alpha\,d\mechanical{\lambda}$. In general $\mechanical{\lambda}$ is not an affine parameter, but in special situations in

![[relativists-toolkit-fig-3-2-null-generators.svg|**Fig. 3.2** A null hypersurface and its generators.]]

<!-- PDF page 78; printed page 62 -->

which the relations $\Phi(x^\alpha)=\text{constant}$ describe a whole family of null hypersurfaces (so that $\Phi_{,\beta}\Phi^{,\beta}$ is zero not only on $\Sigma$ but also in a neighbourhood around $\Sigma$), $\mechanical{\kappa}=0$ and $\mechanical{\lambda}$ is an affine parameter.

When the hypersurface is null, it is advantageous to install on $\Sigma$ a coordinate system that is well adapted to the behaviour of the generators. We therefore let the parameter $\mechanical{\lambda}$ be one of the coordinates, and we introduce two additional coordinates $\theta^A$ $(A=2,3)$ to label the generators; these are constant on each generator, and they span the two-dimensional space transverse to the generators. Thus, we shall set

$$
y^a=(\mechanical{\lambda},\theta^A)
\tag{3.6}
$$

when $\Sigma$ is null: varying $\mechanical{\lambda}$ while keeping $\theta^A$ constant produces a displacement along a single generator, and varying $\theta^A$ produces a displacement across generators.

## Physical quantities

| Symbol | Unit | Quantity | Description |
| --- | --- | --- | --- |
| $n^\alpha,n_\alpha$ | — | Unit normal | The normalized hypersurface normal with coordinate-dependent component units. |
| $g^{\mu\nu}$ | — | Inverse metric | The inverse spacetime metric used to normalize the normal. |
| $\mechanical{k}^\alpha,\mechanical{k}_\alpha$ | — | Null normal and tangent | The normal that also generates the null hypersurface. |
| $\mechanical{\kappa}$ | $\unit{\mathrm{m^{-1}}}$ | Nonaffinity parameter | The coefficient in the general geodesic equation. |
| $\mechanical{\lambda}$ | $\unit{\mathrm{m}}$ | Generator parameter | The curve parameter in geometrized units. |
| $x^\alpha,y^a,\theta^A$ | — | Coordinates | The spacetime, hypersurface, and transverse generator coordinates. |
