> [!TLDR]
> An auxiliary null vector defines a two-dimensional transverse metric orthogonal to both null directions.

<!-- PDF page 62; printed page 46 -->

To isolate the part of the metric that is transverse to $\mechanical{k}^\alpha$ is not entirely straightforward when $\mechanical{k}^\alpha$ is null. The new expression $h'_{\alpha\beta}=g_{\alpha\beta}+\mechanical{k}_\alpha\mechanical{k}_\beta$ does not work, because $h'_{\alpha\beta}\mechanical{k}^\beta=\mechanical{k}_\alpha\ne0$. To see what must be done, let us go to a local Lorentz frame at some point $P$, and let us introduce the null coordinates $\mechanical{u}=\mechanical{t}-\mechanical{x}$ and $\mechanical{v}=\mechanical{t}+\mechanical{x}$. The line element can then be expressed as $d\mechanical{s}^2\stackrel{*}{=}-d\mechanical{u}\,d\mechanical{v}+d\mechanical{y}^2+d\mechanical{z}^2$. Supposing that $\mechanical{k}^\alpha$ is tangent to the curves $\mechanical{u}=\text{constant}$, we see that the transverse line element is $d\mechanical{\tilde s}^2\stackrel{*}{=}d\mechanical{y}^2+d\mechanical{z}^2$: the transverse metric is *two-dimensional*. This clearly has to do with the fact that $d\mechanical{s}^2=0$ for displacements along the $\mechanical{v}$ direction.

To isolate the transverse part of the metric we need to introduce *another* null vector field $N_\alpha$, such that $N_\alpha\mechanical{k}^\alpha\ne0$. Because the normalization of a null vector is arbitrary, we may always impose $\mechanical{k}^\alpha N_\alpha=-1$. If $\mechanical{k}_\alpha\stackrel{*}{=}-\partial_\alpha\mechanical{u}$ in the local Lorentz frame, then we might choose $N_\alpha\stackrel{*}{=}-\tfrac12\partial_\alpha\mechanical{v}$. Now consider the object $h_{\alpha\beta}=g_{\alpha\beta}+\mechanical{k}_\alpha N_\beta+N_\alpha\mechanical{k}_\beta$. This is clearly orthogonal to both $\mechanical{k}^\alpha$ and $N^\alpha$: $h_{\alpha\beta}\mechanical{k}^\beta=h_{\alpha\beta}N^\beta=0$. Furthermore, $h_{\alpha\beta}\stackrel{*}{=}\operatorname{diag}(0,0,1,1)$ in the local Lorentz frame, and $h_{\alpha\beta}$ is properly transverse and two-dimensional. This, then, is the object we seek.

The transverse metric is therefore obtained as follows: Given the null vector field $\mechanical{k}^\alpha$, *select* an auxiliary null vector field $N_\alpha$ and choose its normalization to be such that $\mechanical{k}^\alpha N_\alpha=-1$. Then the transverse metric is given by

$$
h_{\alpha\beta}=g_{\alpha\beta}+\mechanical{k}_\alpha N_\beta+N_\alpha\mechanical{k}_\beta.
\tag{2.28}
$$

It satisfies the relations

$$
h_{\alpha\beta}\mechanical{k}^\beta=h_{\alpha\beta}N^\beta=0,\qquad
h^\alpha{}_\alpha=2,\qquad h^\alpha{}_\mu h^\mu{}_\beta=h^\alpha{}_\beta,
\tag{2.29}
$$

which confirm that $h_{\alpha\beta}$ is purely transverse (orthogonal to both $\mechanical{k}^\alpha$ and $N^\alpha$) and effectively two-dimensional.

Evidently, the conditions $N^\alpha N_\alpha=0$ and $\mechanical{k}^\alpha N_\alpha=-1$ do not determine $N_\alpha$ uniquely. This implies that the transverse metric is *not unique*. As we shall see, however, quantities such as the expansion of the congruence will turn out to be the

same for *all* choices of auxiliary null vector. Further aspects of this non-uniqueness are explored in Section 2.6, Problem 6.
